# Cowboy City — La Traque de Mac Blain

Jeu d'enquête western : parcourez la ville à pied, interrogez les habitants,
suivez les indices jusqu'à la cachette du bandit Mac Blain… et gagnez le duel
sur la place !

**Jouer :** https://pierreflory-web.github.io/cowboy-city/

Un seul fichier HTML, sans dépendances — graphismes SVG façon bande dessinée
western et musique générée en WebAudio.
